# 🤖 LIO 229 - Bot WhatsApp

Bot WhatsApp multi-fonctions basé sur la bibliothèque Baileys, conçu pour une gestion efficace des groupes et des fonctionnalités de divertissement.

## 🚀 Fonctionnalités principales

✅ **Gestion de Groupe** : Tagall, Kick, Ban, Mute/Unmute, Antilink.
✅ **Téléchargements** : YouTube (MP3/MP4), TikTok, Instagram, Facebook, Spotify.
✅ **Intelligence Artificielle** : Chat IA (Gemini 2.0), Génération d'images (Flux).
✅ **Divertissement** : Memes, Citations, Défis (Dare), Vérités (Truth).
✅ **Outils** : Sticker maker, Text-to-Speech, Screenshot web, Traduction.

---

## 🛠️ Installation & Déploiement

### Pré-requis
- Node.js (v18+)
- FFmpeg
- yt-dlp (recommandé pour les téléchargements)

### Installation locale
1. Clonez le dépôt.
2. Installez les dépendances : `npm install`.
3. Lancez le bot : `npm start`.
4. Scannez le code QR ou utilisez le code de jumelage via le terminal.

---

## ⚙️ Configuration
Modifiez le fichier `settings.js` pour configurer :
- Votre numéro (Propriétaire)
- Le nom du bot
- Les clés API (OpenRouter, etc.)
